# Памятка для защиты

1. Показать форк, ветку `variant-12-recycle` и историю коммитов.
2. В `device.hpp` показать `calculated_`, `isCalculated()` и `resetCalculated()`.
3. В `recycle.cpp` показать `checkRecycle()` и `hasDirectedCycle()`.
4. Запустить `RUN_DEMO.cmd`: открытая цепочка не выдаёт предупреждение, D1 → D2 → D1 выдаёт `Recycle warning`.
5. Запустить `RUN_TESTS.cmd`: 27 тестов.
6. В Actions показать зелёные jobs и артефакт покрытия.

На вопрос «что такое рецикл?» ответ: возврат потока в ранее пройденный аппарат, то есть ориентированный цикл графа. Флаг ставится только после успешного расчёта, а перед новым проходом сбрасывается. Связь определяется общей сущностью `Stream`, а не одинаковым текстовым именем.

Учебное правило «получатель уже рассчитан» зависит от порядка расчёта, поэтому добавлен DFS с белыми, серыми и чёрными вершинами. Серый узел находится в текущем пути, переход к нему замыкает цикл; чёрный уже полностью обработан и циклом не считается.

GoogleTest возвращает ненулевой код при ошибке, поэтому CI реально обнаруживает падение. Бейдж строится из gcovr JSON после тестов.
